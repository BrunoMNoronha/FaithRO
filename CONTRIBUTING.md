# Contribuição

## Fluxo

1. Criar issue.
2. Criar branch.
3. Fazer alteração pequena.
4. Testar.
5. Abrir PR.
6. Aguardar revisão.

## Convenção de commits

- `docs:`
- `feat:`
- `fix:`
- `infra:`
- `balance:`

## Pull Request

Inclua:

- resumo
- arquivos alterados
- como testar
- riscos
- rollback
