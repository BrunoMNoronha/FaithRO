# Checklists

## Checklist de PR

- [ ] A mudança tem objetivo claro.
- [ ] Não há segredos.
- [ ] Não há arquivos proprietários.
- [ ] Foi testada localmente.
- [ ] Documentação atualizada.
- [ ] Rollback descrito.

## Checklist de deploy

- [ ] Backup feito.
- [ ] Janela de manutenção comunicada.
- [ ] Serviços atuais funcionando antes da mudança.
- [ ] Mudança aplicada.
- [ ] Serviços reiniciados.
- [ ] Login testado.
- [ ] Personagem entrou no mapa.
- [ ] Logs verificados.
- [ ] Changelog atualizado.

## Checklist de balanceamento

- [ ] Teste com classe física.
- [ ] Teste com classe mágica.
- [ ] Teste com classe suporte.
- [ ] Teste de up 1-255 (base level).
- [ ] Teste de atributos naturais até o limite individual 185.
- [ ] Teste de ASPD até o limite 197 (por classe e tipo de arma; tentativa de exceder 197).
- [ ] Teste de MVP.
- [ ] Teste de economia/drop.
- [ ] Teste de PvP/WoE, se habilitado.
