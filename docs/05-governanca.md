# Governança do projeto

## Princípios

- Comunidade antes de monetização.
- Transparência.
- Estabilidade antes de novidades.
- Customização com moderação.
- Sem pay-to-win.
- Mudanças rastreáveis.

## Regras para mudanças

Toda mudança deve ter issue ou tarefa com:

- motivo
- escopo
- arquivos envolvidos
- teste
- risco
- rollback

## Política de IA

ChatGPT, Claude e Copilot podem ajudar com:

- documentação
- scripts
- análise de configuração
- revisão de PR
- checklists
- balanceamento inicial

Agentes de IA não devem:

- inventar configurações sem validação
- expor segredos
- gerar material proprietário
- aplicar mudanças em produção sem aprovação humana

## Registro de decisões

Use ADRs em `docs/adr/`.

Formato:

- Contexto
- Opções
- Decisão
- Consequências
- Data
